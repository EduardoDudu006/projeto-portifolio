Projeto Quizz Interativo

Projeto construído para treinar efeito paralax em imagem.

Saiba mais...

O código estruturado no documento HTML apresenta o esqueleto de um aplicativo web de entretenimento educativo e gamificado focado no desenvolvimento frontend. Durante a partida, a experiência de jogo é enriquecida por recursos de suporte, como o acionamento de dicas estruturadas. Por fim, a tela de encerramento aplica elementos de gamificação ao saudar o usuário pelo nome, exibir um sumário pedagógico com o gabarito das respostas e disparar efeitos visuais com manipulação de gráficos via elemento

Projeto Android

Projeto construído para treinar conteúdos e imagens dinâmicas.

Saiba mais...

O Android é o sistema operacional para dispositivos móveis mais utilizado no mundo, mantido pelo Google. Sua trajetória visual é marcada por uma evolução de identidade: começou em 2007 com os "Dandroids" (uma versão inicial vetorial criada por Dan Morrill) e se consolidou com o icônico Bugdroid, o robô verde projetado pela ilustradora Irina Blok com traços simples e minimalistas inspirados em placas de banheiro. Culturalmente, o sistema ficou conhecido por batizar suas versões estáveis com nomes de doces em ordem alfabética (do Cupcake 1.5 ao Pie 9.0), prática comercial que foi descontinuada a partir do Android 10 para adotar uma nomenclatura puramente numérica.

Projeto Redes Sociais

Projeto construído para treinar navegabilidade entre páginas.

Saiba mais...

O projeto tem a estrutura base de uma aplicação interativa que simula a interface de um dispositivo móvel integrado a um painel de navegação de redes sociais. O núcleo funcional do projeto baseia-se no uso estratégico do elemento <iframe>, que atua como uma tela interna dinâmica (batizada com o atributo name="tela"). Essa tag é responsável por carregar de forma isolada os conteúdos assíncronos das páginas externas e internas diretamente na seção principal do layout, permitindo que o usuário navegue entre diferentes plataformas sem sair da página mãe.

A experiência do usuário é centralizada em uma barra lateral composta por hiperlinks vinculados a imagens responsivas que representam canais populares da internet, como YouTube, GitHub, Instagram, LinkedIn e TikTok. Ao clicar em qualquer um desses logotipos, o atributo target="tela" redireciona o carregamento do endereço solicitado exclusivamente para o interior do quadro do simulador, reproduzindo de forma limpa a usabilidade real de um smartphone. Trata-se de uma solução puramente estrutural em HTML5 que demonstra conceitos sólidos de modularidade de conteúdo, preparação para folhas de estilo em cascata e integração de navegação limpa focada em portfólios pessoais.

Projeto Hamburgueria

Projeto construído para simular um e-comerce de fast-food.

Saiba mais...

O código estruturado no documento HTML apresenta uma página de vendas (landing page) focada na conversão e na experiência do usuário para o comércio eletrônico local de uma marca de alimentação no Recife. A arquitetura do código adota padrões modernos de semântica web ao delimitar o cabeçalho de navegação fixa, a apresentação de impacto visual inicial na seção hero e o catálogo comercial na grade de produtos. O principal diferencial estratégico do projeto está no modelo descentralizado de fechamento de vendas através da API de redirecionamento do WhatsApp integrado a cada item individual do cardápio, permitindo a interação direta e ágil com o consumidor.

Adicionalmente, a estrutura técnica demonstra uma sólida preocupação com gatilhos de engajamento psicológico ao destacar distintivos de novidade e volume de saídas, métricas explícitas de prova social e prazos de entrega rigorosos na dobra principal do layout. O código serve como um excelente modelo de interface focada em dispositivos móveis, estruturado em uma lista ordenada passível de estilização responsiva em grade bidimensional no CSS para otimizar a vitrine virtual dos hambúrgueres gourmet.
